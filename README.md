# 🪨📄✂️ Stone Paper Scissors

A classic browser-based **Stone Paper Scissors** game built with vanilla HTML, CSS, and JavaScript.

## 🎮 Live Demo
[Play the game live on Render](#) *https://stone-paper-scissor-9xuu.onrender.com*

## ✨ Features
* **Interactive Gameplay:** Click on the Stone, Paper, or Scissors icons to make your move.
* **Computer Opponent:** Random move generation for the computer player.
* **Live Scoreboard:** Automatically tracks player wins, computer wins, and draws.
* **Clean Interface:** Styled with custom CSS and visual hand icons.

## 🛠️ Built With
* **HTML5** – Page structure and game layout
* **CSS3** – Styling, layout, and button hover effects
* **JavaScript (ES6)** – Game logic, random move selection, and score tracking

## 🚀 How to Run Locally
1. Clone or download this repository to your computer.
2. Open the project folder.
3. Double-click `index.html` to open and play the game in any web browser.

## 📜 Game Rules
* **Stone** crushes **Scissors**
* **Scissors** cuts **Paper**
* **Paper** covers **Stone**
* Identical choices result in a **Draw**
